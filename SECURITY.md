# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests. Use GitHub's private vulnerability reporting or security advisory
feature for this repository when available. Include steps to reproduce,
potential impact and any suggested mitigation.

If private reporting is unavailable, contact the repository maintainers
privately through a verified channel listed on the repository's GitHub
organization profile. Do not include sensitive data in a public report.

## Scope

This repository is currently an architecture scaffold and does not yet provide
an operational ingestion service or hosted application. Security reports
concerning the documentation, schemas, examples or repository automation are
still welcome.

For design guidance on handling untrusted source material, see
[`docs/SECURITY.md`](docs/SECURITY.md).
